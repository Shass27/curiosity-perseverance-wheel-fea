# Parametric CAD Models & Design Sweep

This folder contains parametric STEP files used for structural analysis and design optimization studies (such as rover wheel grousers and feature-based components). 

##  Folder Structure & Parameter Matrix

The dataset is organized across **5 distinct features**, with each feature containing an evaluation matrix of **18 unique parametric variations** (Total = 90 STEP files).

### Variation Parameters
The 18 configurations per feature are generated by systematically varying three key geometric parameters:
* **`r`** (Fillet Radius): 3 variations
* **`t`** (Skin Thickness): 2 variations
* **`s`** (Grouser Spacing): 3 variations

**Total Files per Feature** = 3 (Radius) × 2 (Thickness) × 3 (Spacing) = 18 files
